============================================================
ENERWISE - RUN COMMANDS
============================================================

1) افتح CMD وروح للمشروع
------------------------------------------------------------
cd /d E:\EnerWise


2) شغّل كل Docker services
------------------------------------------------------------
docker compose up -d


3) تأكد إن Kafka + Hadoop + Spark شغالين
------------------------------------------------------------
docker compose ps


4) تأكد إن Spark شغال من Docker
------------------------------------------------------------
docker exec enerwise-spark /opt/spark/bin/spark-submit --version


5) تأكد إن ملفات Spark موجودة
------------------------------------------------------------
docker exec enerwise-spark ls -l /opt/spark/work-dir


6) شغّل Spark ETL / Cleaning
------------------------------------------------------------
docker exec -it enerwise-spark \
/opt/spark/bin/spark-submit \
--master spark://spark:7077 \
/opt/spark/work-dir/enerwise_etl.py


7) تأكد إن الـ CLEANED DATA اتخزنت في HDFS
------------------------------------------------------------
docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/processed/energy


8) شوف الـ cleaned data
------------------------------------------------------------
docker exec enerwise-namenode \
hdfs dfs -cat /enerwise/processed/energy/part-*.json | head


9) تأكد إن الـ Analytics موجودة
------------------------------------------------------------
docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/analytics


10) شوف كل الـ Analytics folders
------------------------------------------------------------
docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/analytics/energy_by_building

docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/analytics/energy_by_hvac

docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/analytics/energy_statistics

docker exec enerwise-namenode \
hdfs dfs -ls /enerwise/analytics/ml_features


============================================================
HDFS STRUCTURE
============================================================

/enerwise/raw/energy
        ↓
   Raw JSON batches
        ↓
      Spark
        ↓
Cleaning
        ↓
/enerwise/processed/energy
        ↓
Processing / Analytics
        ↓
/enerwise/analytics/
    ├── energy_by_building
    ├── energy_by_hvac
    ├── energy_statistics
    └── ml_features


============================================================
IMPORTANT
============================================================

/opt/spark/bin/spark-submit \
